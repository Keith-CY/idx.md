  # Redesign Skill

  ## How This Works

  When applied to an existing project, follow this sequence:

  1. **Scan** — Read the codebase. Identify the framework, styling method
  (Tailwind, vanilla CSS, styled-components, etc.), and current design patterns.

  2. **Diagnose** — Run through the audit below. List every generic pattern,
  weak point, and missing state you find.

  3. **Fix** — Apply targeted upgrades working with the existing stack. Do not
  rewrite from scratch. Improve what's there.
