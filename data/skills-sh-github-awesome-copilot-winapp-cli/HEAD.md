  # CLI Documentation and Usage

  ## Version

  Print the installed winapp version with `--version` or its short form `-V`:

  ```powershell

  winapp -V

  ```

  Lowercase `-v` is the short form of `--verbose` on commands (for example,
  `winapp restore -v`).
