  # OpenClaw Skill Reference

  ## Product summary

  OpenClaw is a self-hosted gateway that connects messaging apps (WhatsApp,
  Telegram, Discord, iMessage, Signal, and more) to AI agents. A single Gateway
  process runs on your machine or server and routes inbound messages to agents,
  manages sessions, handles tool execution, and streams responses back to
  channels. Key files: `~/.openclaw/openclaw.json` (config),
  `~/.openclaw/workspace/` (agent workspace with AGENTS.md, SOUL.md, TOOLS.md),
  `~/.openclaw/agents/<agentId>/sessions/` (session transcripts). Primary CLI:
  `openclaw` with subcommands for setup, configuration, channels, agents,
  models, and gateway control. See https://docs.openclaw.ai for comprehensive
  documentation.
