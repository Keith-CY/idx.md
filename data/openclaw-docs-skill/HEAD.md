  # OpenClaw Skill Reference

  ## Product summary

  OpenClaw is a self-hosted gateway that connects messaging apps (WhatsApp,
  Telegram, Discord, iMessage, Signal, Slack, Mattermost, and more) to AI
  agents. It runs on any OS (macOS, Linux, Windows via WSL2) and manages
  sessions, routing, media, and tool execution. Agents use a workspace directory
  (`~/.openclaw/workspace`) containing bootstrap files (AGENTS.md, SOUL.md,
  TOOLS.md, IDENTITY.md, USER.md) that inject context on every turn.
  Configuration lives in `~/.openclaw/openclaw.json` (JSON5 format). Key CLI:
  `openclaw onboard`, `openclaw gateway`, `openclaw config`, `openclaw
  channels`, `openclaw agent`, `openclaw message`. Primary docs:
  https://docs.openclaw.ai
