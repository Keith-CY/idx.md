  # OpenClaw Agent Skill

  ## Product summary

  OpenClaw is a self-hosted AI agent gateway that runs a single embedded agent
  runtime with its own workspace, sessions, and tool access. It connects agents
  to 30+ messaging channels (Discord, Slack, Telegram, WhatsApp, Signal, Matrix,
  Feishu, etc.), supports multi-agent routing with isolated workspaces, and
  provides browser automation, web search, code execution, and custom skills.
  The primary config file is `~/.openclaw/openclaw.json` (JSON5 format). Key CLI
  entry point: `openclaw` (gateway, agent, config, channels, skills, cron
  commands). Primary docs: https://docs.openclaw.ai
